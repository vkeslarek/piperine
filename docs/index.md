# Piperine Documentation

Piperine simulates analog, digital and mixed-signal circuits written in **MSL**,
the Piperine mixed-signal language.

Choose a section from the navigation menu:

* **The MSL Book**: the user manual. Part 1, *Fundamentals*, teaches the
  language, running simulations and the `piperine` command line. Part 2,
  *In depth*, covers the object model, the device ABI, the solver and how
  Piperine is organized. Its sources are in `docs/book/`.
* **Specification**: `docs/spec/`, the authoritative definition of MSL:
  values, carriers, structure, behavior, execution, input and output, the
  standard library and the host, with the grammar and the galleries in the
  appendices.
* **Object model**: `docs/pom/`, how the object model stores and resolves a
  design.
