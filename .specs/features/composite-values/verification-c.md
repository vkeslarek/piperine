**Own examples** (throwaway `crates/piperine-lang/tests/zz_verifier_probe.rs`, deleted, at 7033d22c; elaborated with the real stdlib):

- QC2, an array length read from a param: `module Top() { n: u32 = 4; signal s: [Bit; n]; }` and a port `in d: [Bit; n]` are both `E0188` "the length of an array type is a constant, and `n` is not one the checker folds". Fails (Finding 1).
- Length 0, which §1.2.3 allows ("known and not negative"): `signal none: [Bit<u8>; 0];` is `P0004 internal error: elaboration produced an ill-formed IR: carrier none is an array of no element`. Fails (Finding 3). Length 1 elaborates (`count=Some(1)`). Holds.
- One drive per element, the run-time index against a function's drive (the implementer's known gap), every MSL route I could write: a definition `bits[0] = a` beside `bits[i % 4] <- true` is `E0221`; `lines[3]` handed to a child's `out` port beside a run-time commit of `lines[i % 4]` is `E0220`; a whole `lines` handed to a child that commits `q[i % 4]` beside a sibling child driving `lines[0]` is `E0220` (second `out` port); a parent definition `lines[0] = a` beside a child committing `q[i]` is `E0220`; a child defining `q[0]` and committing `q[i]` itself is `E0221`. A constant commit of `lines[1]` beside `lines[3]` handed out is accepted. Holds for MSL; the engine's own P1 exempts the pair (Finding 5).
- A constant element past the end in a reaction, `s[4] <- true` on `[Bit; 4]`: `E0104` "the element 4 is out of range for an array of 4 carriers". Holds.
- A run-time element index in an event head, `on s[i].changed()`: `E0180` naming `s[i]` (QC4 as amended; Finding 4 on the code).
- An array of carriers as a `let` type in a reaction: `P0001` naming the form. Holds (QC3).
