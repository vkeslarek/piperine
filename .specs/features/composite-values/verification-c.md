**Questions judged:**

- *A run-time per-commit fault rather than a bind-time refusal* - acceptable. The rule the user set is "never a silent last write"; a fault names the net, the element and P1 and stops the analysis before the value lands. A bind-time refusal could not tell a reaction that only commits elements outside the function's window (C131's legal case, and the test's control with element 6) from one that collides, because the element is chosen at run time. MSL sources never reach the fault (the checker's `E0220`/`E0221`, round 1 own examples); it guards native device shapes.
- *Zero length without touching the ABI count encoding* - no hole found (above): the elaborator never makes a pin for an empty array, so no shape carries `count` 0 for one. The one gap is the host name (Finding 16).
- *natures#2* - the GAPS row's owner is right: with the `logic` literal folding, the only language refusal left is `Sda` (`E0161`), which is resolved-nets' (L21). The stand-in run's `E0503` is not a language gap: the listing is a list of declarations, so `mid` and `vout` float and no operating point exists. The record is incomplete outside GAPS.md (Finding 17).
- *Commit f7487b45's subject fails `check_commit.py`* - process note only (force-push denied, history kept); no finding.
- QC4 as `E0188` with `docs/spec/part_i_values.md`'s `E0188` row extended to name the element index: follows the user's decision.
